Blender add-on · glTF 2.0 · REST ingest

Handoff

A Blender add-on that checks a scene for the problems that break 3D assets once they leave the artist's machine, exports it as glTF, and publishes it to an ingest API. The client survives retries, rate limits, and dropped acknowledgements without creating duplicates.

03 — What's in the repo

The real building blocks

Python · bpy

The add-on

Sidebar panel, operators, and preferences. Uploads run on a worker thread, and a bpy.app.timers callback redraws the panel, so Blender never freezes. Respects Blender 4.2's Allow Online Access switch.

 Python · no bpy

Preflight rules

Checks color space by texture role, unit mix-ups, shear, procedural nodes, UDIMs, and triangle budgets after modifiers. They run on a plain-data snapshot, so they're unit-tested without Blender.

 Python · stdlib

Ingest client

Three-step presigned-style upload. Idempotency keys on every POST, exponential backoff with jitter, Retry-After honored, and the API token never forwarded to a different host.

 Python · http.server

Mock ingest server

A local API with fault injection (--fail-first, --rate-limit, --lose-ack). It verifies checksums and rejects bad GLBs during processing, just like the real thing.

 Python · binary parsing

GLB inspector

Parses GLB chunks and validates them against the spec. Counts triangles per rendered instance and computes world-space bounds by walking the node hierarchy's transforms.

 Docs

Troubleshooting guide

Every finding code has an entry: what you see, why it matters downstream, how to fix it. The ? button in Blender links straight to it, and a test fails if a code goes undocumented.
